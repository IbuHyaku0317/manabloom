# ManaBloom 価格・配信地域・輸出コンプライアンス

初版（バージョン1.0）は、日本のApp Storeだけで無料公開する。

## 1. 価格

| 項目 | 設定 |
| --- | --- |
| 基本価格 | 無料（0円） |
| アプリ内課金 | なし |
| サブスクリプション | なし |

楽天アフィリエイトリンクは、アプリ自体の価格やアプリ内課金ではない。

## 2. 配信方式

| 項目 | 設定 |
| --- | --- |
| 配信方式 | 一般公開（Public Distribution） |
| 予約注文 | 使用しない |
| 非公開・組織限定配信 | 使用しない |

一般利用者が日本のApp Storeで検索・ダウンロードできる通常の公開方式を選択する。

## 3. 配信地域

App Store Connectの「価格および配信状況」から設定する。

1. 「アプリの配信状況」で「配信状況を設定」を選ぶ。
2. 「特定の国または地域」を選ぶ。
3. すべての選択を外し、「日本」だけを選ぶ。
4. 将来追加される国・地域へ自動配信する設定は選ばない。
5. 内容を確認して確定する。

```text
配信対象：日本のみ
```

海外配信を始める場合は、対象地域、ストア掲載文の言語、法的表示、楽天アフィリエイトの対象地域およびプライバシー情報を再確認する。

## 4. 輸出コンプライアンス

### 現在の実装

- 独自または非標準の暗号化アルゴリズムを実装していない。
- 暗号化を目的とする機能を利用者へ提供していない。
- HTTPS等でiOSが提供する標準的な暗号化機能だけを利用する。
- Capacitor、FilesystemおよびShareに独自暗号化機能はない。

### Xcode設定

`ios/App/App/Info.plist`へ次を設定済み。

```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

意味：

```text
App Uses Non-Exempt Encryption：NO
```

これは、アプリが暗号化をまったく使用しない、または輸出コンプライアンス上の免除対象となる暗号化だけを使用することを示す。

### App Store Connectで質問された場合の回答方針

画面の質問文は更新される場合があるため、文章を確認して回答する。現在の実装では次の内容になる。

```text
独自・非標準の暗号化：使用しない
AppleのOS以外で実装した暗号化：使用しない
輸出コンプライアンス書類：不要の想定
```

暗号化ライブラリ、独自通信、VPN、メッセージ暗号化、パスワード管理または暗号資産機能を追加した場合は、この回答を再確認する。

## 5. 日本のみ配信による初版の整理

- ストア主言語：日本語
- 価格：無料
- 配信地域：日本
- 配信方式：一般公開
- アプリ内課金：なし
- 予約注文：なし
- App Privacy：データを収集しない
- 年齢区分：広告あり、その他の該当項目なし
- 輸出コンプライアンス：非免除の暗号化なし

## 6. 提出前チェック

- App Store Connectで選択地域が「日本」のみになっている。
- 価格が無料になっている。
- Public Distributionになっている。
- 誤って予約注文を有効にしていない。
- ビルドに`ITSAppUsesNonExemptEncryption = NO`が含まれている。
- 新しいSDKや暗号化機能を追加していない。
